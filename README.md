# Ethica &mdash; Helvetica Coming Soon

A minimalist, high-precision Coming Soon landing page for the **Helvetica** font identity in **Ethica** by **Bugstex Technologies**.

Designed with the clarity, neutrality, and structural rigor of Swiss Modernist typography.

## Features

- **Iconic Swiss Design**: High-contrast, clean grid layout built specifically to celebrate the Helvetica typeface.
- **Specimen Showcase**: Interactive preview of weights and glyphs (Light, Regular, Bold).
- **Responsive & Lightweight**: Pure HTML5, modern CSS3 (custom properties, fluid clamp typography), and vanilla JavaScript with zero external runtime dependencies.
- **Dark / Light Mode**: Automatically adapts to user system preference with instant local toggle and persistence.
- **Cloudflare Ready**: Ready for direct deployment on Cloudflare Pages or Cloudflare Workers Sites with zero build configuration.

## Deploying to Cloudflare Pages

1. In your Cloudflare dashboard, navigate to **Compute (Workers) > Pages**.
2. Select **Connect to Git** and choose the `Bugstex-Technologies/coming-soon` repository.
3. Configure build settings:
   - **Framework preset**: None
   - **Build command**: (Leave empty)
   - **Build output directory**: `/` (or leave blank)
4. Click **Save and Deploy**.
