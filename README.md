# Bugstex Technologies — Coming Soon (`bugstex.com`)

Minimalist frontier AI assurance & governance landing page for **Bugstex Technologies**, built for zero-config static deployment on **Cloudflare Pages**.

## Structure

- `index.html` — Single-page frontier B2B interface (Platform overview, interactive alignment telemetry simulation, executive leadership, and direct contact channels).
- `styles.css` — Architectural dark/light design system.
- `script.js` — Interactive 7-axis alignment radar canvas, domain profile switcher, theme controller, and priority access waitlist capture.
- `assets/` — Transparent dark/light adaptations of the official Bugstex emblem and wordmark.

## Deploying to Cloudflare Pages

1. Connect `Bugstex-Technologies/coming-soon` in **Cloudflare Dashboard → Compute (Workers & Pages) → Pages**.
2. Leave **Framework preset** as `None`, **Build command** empty, and **Build output directory** as `/`.
3. Attach custom domain `bugstex.com` and `www.bugstex.com`.
